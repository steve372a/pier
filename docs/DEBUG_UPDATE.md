# Pier 自动更新功能调试指南

## 本地调试步骤

### 1. 模拟强制更新场景

修改 `share/cache/ver.sque`：
```
29322221199998524
2.3.2,>=2.3.1(FORCE)
```

这表示：
- 最新版本：2.3.2
- 最低要求：2.3.1
- 低于 2.3.1 强制更新

### 2. 降低当前版本号

修改 `piec.bat` 中的版本号：
```batch
SET version=2.2.9
```

### 3. 准备测试用的 Release

在 GitHub 上创建 Release：
- Tag: `v2.3`
- 上传文件: `pier-2.3.2.zip`（可以是任意测试文件）

### 4. 运行测试

```bash
piec install bb
```

预期输出：
```
pier - 软件包安装器 Windows(CMD) 版本 2.2.9
最新分发的版本为：2.3.2
你目前的版本 (2.2.9) 无法使用。请立刻更新至最新版本！

正在更新 Pier Package Installer...
正在下载新版本 Pier，版本 2.3.2...
解压中...
更新完成！请重新运行 pier。
请按任意键继续...
```

## 回滚方法

如果更新后有问题：
1. 手动删除 `update.cmd`
2. 恢复 `ver.sque` 为正常版本
3. 重新运行 `piec`

## 注意事项

1. **测试前备份** - 复制整个 pier 目录到 `pier-backup`
2. **网络问题** - 确保能访问 `github.com`
3. **权限问题** - 确保有写入权限
