2.4.0
1. scuts 快捷方式：安装包时自动创建 scuts/包名.bat，卸载时自动删除
   - 使用 %~dp0 动态路径解析，无论 Pier 目录在哪都能用
   - pier updpath 命令：一键将 scuts 目录加入用户 PATH
   - piercmd.bat 自动追加 scuts 到会话 PATH
2. 消灭所有 system() 调用：全部替换为 CreateProcess 或纯 C 实现
   - copy → CopyFileA, rd → dir_remove(), sed -i → remove_line_from_file()
   - 所有外部工具调用统一用 CreateProcessA
3. 移除 short_root / GetShortPathNameA 依赖
4. MAX_LANG_STRINGS 扩展到 512，支持更多翻译字符串
5. 删除 uma-get.exe (3MB)、sed.exe 等冗余文件
6. UTF-8 转 ACP 转换，兼容全球语言，XP 可用
7. pier-uni.exe：新增工具，支持 stdin 管道模式（类似 iconv）
8. 修复 notice.sque 仅有 \r 行尾的处理问题
9. SQUE 条件语法解析引擎 + squecheck.exe 语法检查器
    - if <条件> then <行为>[else <行为>]; 单行条件语法
    - {systemver}、{os} 只读变量，{version}、{packagesize} 可被条件赋值
    - 全部大小写不敏感（关键字、变量名、引号内比较值）
    - squecheck.exe 检测 7 类语法错误（缺分号、单等号、引号/括号不匹配、未定义变量、缺 then、只读赋值）
    - if 语句必须位于 [Script] 区段内
    - pier sque -c/check <文件> 路由调用
    - 输出统一使用 vecho.exe
10. pier hash 命令 & SHA256 校验
    - pier hash -g/gene <文件>：生成文件 SHA256
    - pier hash -c/check <文件1> <文件2>：对比两个文件的 SHA256
    - 哈希匹配输出 OK!（绿色），不匹配输出 FAIL!（红色）
    - 所有输出使用 vecho.exe，消息从 languext.ini 读取
    - metadata.sque 新增 [HASH] 字段，pier-pkg 安装时自动 SHA256 校验
    - sque_read 区段匹配改为大小写不敏感（_strnicmp）
11. help.lang 更新：新增 Hash 命令和 SQUE 语法检查帮助信息
12. XP TLS/SSL 兼容性修复
    - pier-get：改用 MinGW-w64 + 静态 OpenSSL（libcurl 7.56.1 + libssl + libcrypto）编译
    - `-static -static-libgcc`：纯静态链接，消除 libwinpthread-1.dll 依赖
    - `-D_WIN32_WINNT=0x0501 -DWINVER=0x0501`：消除 GetTickCount64 等 Vista+ API
    - ~3MB，仅依赖系统 DLL（kernel32/user32/gdi32/advapi32/msvcrt/ws2_32）
    - XP/Win7/Win10/Win11 全版本原生 TLS 1.2+
    - 其他工具继续用 TCC 编译
13. XP 安装/运行兼容性修复
   - CREATE_NO_WINDOW (0x08000000) 是 Vista+ 标志，XP 不支持
   - pier-pkg.c: run_silent() 修复返回值为实际结果 + XP fallback 重试
   - pier-pkg.c: capture_output() 添加 XP fallback
   - pier-pkg.c: install_package() 新增验证机制（CreateDirectoryA/run_silent 检查 + FindFirstFileA 目录非空验证）
   - pier-op.c: download_alias_template()/download_metadata() 中 pier-get + unzip 调用添加 XP fallback
   - pier-ver.c: 版本检查下载添加 XP fallback
   - lang.ini 新增 error_install_dir_failed/error_install_unzip_failed/error_install_empty/error_hash_failed/error_verify_failed（zh-CN + en-US）
   - SHA256 校验错误信息改用语言字符串
14. pier-get XP 偶尔崩溃修复 + 下载速度优化
   - XP 多线程下载间歇性崩溃 → 根因为多线程 OpenSSL 初始化竞态，XP 强制单线程
   - pier-get 新增 -b 批量下载模式：同进程依次下载多个文件
   - pier-pkg.c install/remove 改用批量下载，元数据只启动 1 次 pier-get 代替 N 次
15. 修复 pier o <包名> "无法获取包元数据" bug
   - 根因：skip_section 逻辑缺陷，替换 [PackageName] 后一直等待 ::end 才释放
   - 原始 metadata.sque 各 section 之间无 ::end 标记（仅 [DefaultOpen] 末尾有）
   - 导致 [InstallerName]/[Version]/[OS]/[URL] 等关键字段被全部跳过
   - 修复：skip_section 遇到 [ 开头的 section 头时自动释放
    - 影响文件：pier-op.c（download_metadata 保存逻辑）、pier-pkg.c（parse_metadata 保存逻辑）
16. 修复 pier install <包名> 所有显示字段为空 bug
    - parse_metadata 调用条件取反：metadata_downloaded=1 表示成功，但代码用 `if (downloaded) continue` 跳过了
    - 正确应为 `if (!downloaded) continue`（只解析下载成功的包）
    - 影响 pier install 和 pier remove 两条路径
17. 修复 pier o <不存在包名> 缓存污染导致打开错误程序 bug
   - 例：`pier o 3` 打开了 `czadb` — 因为 share\cache\metadata.sque 残留上次的旧数据
   - 根因①：pier-op.c download_metadata() 下载前不清理旧缓存
   - 根因②：pier-get 下载 404 页面仍创建文件，unzip 失败但旧 metadata.sque 被误判为有效
   - 根因③：pier install 用户取消时未清理缓存
   - 修复①：pier-op.c 下载前先 remove 旧 metadata.sque/notice.sque/profile.sque
   - 修复②：pier-op.c + pier-pkg.c 解压后 sque_read InstallerName 验证内容有效性
   - 修复③：pier-pkg.c 取消安装时增加缓存清理
18. pier-get 批处理 TLS 握手加速（4.4x）
   - 根因：每次下载都 curl_easy_init/cleanup，TLS 会话缓存 per-handle 无法生效
   - 批处理模式宣称 "reusing TLS session" 但实际未复用（每次新建 handle）
   - 修复①：新增 pier_get_download_reuse() — 持久化单个 curl handle 跨请求复用
   - 修复②：批处理中强制 TLS 1.2（CURL_SSLVERSION_TLSv1_2），跳过版本协商
   - 速度：3 个 metadata 从 8.3s → 1.9s（4.4x 加速）
20. pier updpath 支持首次运行时询问是否添加到永久 PATH
   - 旧行为：PATH 中没有 pier 时直接报错 "无需更新"
   - 新行为：询问 "是否添加到永久 PATH？(Y/N)"，Y 则追加 pier\scuts 到 HKCU\Environment\PATH
   - N 则提示可稍后运行 pier updpath 添加
   - lang.ini 新增：updpath_add_prompt、updpath_add_yes、updpath_add_no（zh-CN + en-US）
21. pier info <包名> 命令
   - 显示包详细信息（包名、版本、系统要求、简介、作者、分发者、架构、许可证）
   - 显示别名列表（格式：别名 - 命令）
   - 不触发安装，仅查询信息
   - lang.ini 新增：error_no_package_info（zh-CN + en-US）
   - help.lang 新增：[包信息查询] / [Package Info] 帮助区段

   - lang.ini/help.lang 统一使用 UTF-8 编码
23. PowerShell 脚本 UTF-8 修复
